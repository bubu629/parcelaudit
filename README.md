* **DIM Weight Overcharge Detection:** Automatically recalculates dimensional weight (`L × W × H / 139`) against billed carrier weight.
* **Late Delivery Refund Screener:** Flags Overnight / Next-Day / Express shipments that missed guaranteed transit windows.
* **Duplicate Billing Guard:** Identifies duplicate tracking numbers billed multiple times across carrier statements.
* **Zero Telemetry & Air-Gapped:** Single standalone binary for macOS (Apple Silicon), Windows (x64), and Linux (x64).
